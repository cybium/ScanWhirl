# Why ScanWhirl: identity and "not overwhelming" (lead decision 2026-11-18)

Pipeline: R3 PSYCHOLOGY + R4 WHY_SCANWHIRL -> critics -> JUDGE_WHY (Sol) -> lead ACCEPTS. Full reasoning and the
12 rules' evidence: next/docs/review/JUDGE_WHY.md. This file is the short, binding version.

## Why ScanWhirl
- **Positioning (true today):** for people preparing paperwork and keeping everyday documents: free scanning,
  free single-document target-size compression, text search in scans and merging on the phone, with no account,
  no ads, and no internet permission in the app.
- **Tagline:** EN "Scan it. Size it. Keep it." HI (draft, Hindi-speaker check before use):
  "काग़ज़ स्कैन करें। फ़ाइल तैयार करें।"
- **Jobs:** acquire = prepare a file for a form; return = find, add to and share documents already in the library.
- **Never claim:** "gets accepted", "fits every form", guaranteed size/legibility/OCR, "nothing leaked", "100% safe",
  masking is free, Trash = gone, one-tap 20/50/100/200 KB (until built), a fixed ₹ price, "1 free use" or free folder
  creation (until built), "the only ...", competitor comparisons, real public files before phase 4.

## Feel: Calm. Exact. Yours.
- **Voice:** name the outcome ("File size: 96 KB."), one plain term per concept, say where the original is, give a
  recoverable next action on errors, "{Play price} once. No subscription." No hype, no "Done!", no long dashes.
- **Look:** deep ink + Manrope kept; working accent = calmer cyan `sw_scan #35D9EE` (`rv_accent #62E1F1` where
  contrast needs); no neon glow/glowing borders/halo chips; tonal surfaces; `#00F0FF` only as a small capture-disc
  detail; gold always with "Pro"/lock; category colours muted. Internal sci-fi token names aliased only when touched.
- **Light ("Paper") theme:** LATER, outside phases 1-7.
- **One signature motion, the whirl:** after a capture is safely saved, the mark turns 180° once in 220 ms. Never
  on resume/reload/OCR/Pro results, never loops, never blocks, coalesced, off under "Remove animations". Today it is
  wired only in the legacy MainActivity: wire it into the live capture path (phase 2 motion, phase 6 polish).
- **Signature moments (no new screens):** capture commit (thumbnail + count + whirl); compress result leads with the
  measured size ("Under the selected 100 KB limit" only when true); result Replace/Keep says where the original goes
  + named restore; empty Library/About: "No internet permission. No ads. No account."; A/अ switches language
  without touching documents.

## Not overwhelming (the density ruling)
Keep capability density; reduce interpretation, navigation and risk density. A person must see their document,
recognise the job, know the one primary next action and its consequence, and finish without losing the source.
12 rules (JUDGE_WHY §3): one clear primary action; chunk visually, no magic counts; group by job with icon + label,
no Soon tiles; prevent loss then show recovery; show only real work, honest progress; outcome first, sales copy
subordinate; lead with the measured outcome; one concept one label; max two disclosure levels to find a tool
(Tools -> job -> tool); correctness before decoration; task progress, never engagement pressure (no streaks/pushes);
explain access and limits, never solicit storage permission.
Acceptance: on the Infinix in EN and HI, the owner can scan/import, find Compress, find an old receipt, switch
language, replace then restore a document; 200% font + TalkBack checked. No "looks calm" votes.
