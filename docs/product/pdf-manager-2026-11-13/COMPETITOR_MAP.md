# PDF manager competitor map

Evidence from the 2026-11-13 device walk. Screenshot names are in `../../competitive/2026-11-13/screenshots/`.

## CamScanner — the broadest PDF suite

**PDF surface:** Home has a **PDF Tools** tile. The PDF Tools screen has 11 actions:

- Convert: To Word, To Excel, To PPT, PDF to Images, PDF to Long Image
- Edit: Sign, Add Watermark, PDF Compress, Merge Files, PDF Extract, Reorder Pages, Protect PDF

`cam_pdf_tools.png`

**Document surface:** document view has Add / Edit / Share / To Word / Sign. The editor has Images / Markup / Page tabs. Images includes CS PDF, Crop, Filter, Edit Text, Smart Erase, Retake. Markup includes Sign, Add Text, Brush, Add Watermark, Page Title. Page includes Page Title.

`cam_document2.png`, `cam_editor.png`, `cam_editor_markup.png`

**Files:** import files/images, create folder, All/sort/grid/multi-select, tags.

`cam_files3.png`

**Security:** folder password, 2FA; PDF Tools has Protect PDF.

`cam_settings_security.png`

**Why it feels complete:** it treats PDFs as a file system plus a tool suite. It also has 194 MB of native/OCR/PDF/ad code and 46 permissions; do not copy that cost.

## Adobe Scan — the cleanest document workspace

**Scan options:** Combine files (premium), Create from photos, AI mode, High-speed scan (premium), Create scan.

`01_adobe_camera4.png`

**Saved card:** Share / Save as Word doc (premium) / Digitize Beta / More.

`01_adobe_saved.png`

**Viewer:** Rename, Search, Share; Generative summary; Digitize / Modify / Edit text / Acrobat / More.

`01_adobe_document.png`

**Modify:** Ask AI, Digitize, Retake, Crop, Rotate, Edit text; Keep scanning / Save PDF.

`01_adobe_modify.png`

**Preferences:** naming templates, auto-straighten, OCR on saved PDF, OCR language, default filter.

`01_adobe_preferences.png`, `01_adobe_filename.png`

**Premium feature list:** Magic eraser, Edit text, High-speed scan, export Word/Excel/PowerPoint, Combine, Compress, password, 100-page OCR, 20 GB cloud.

`01_adobe_premium.png`

**Lesson:** the scan sheet and document quick actions are better than a hidden tools sheet. The viewer dock is the strongest model. The price is cloud-first and ads.

## Genius Scan — the clearest free/paid boundary

**Free:** high-resolution scanning, unlimited scans, perspective correction, multipage PDF.
**Ultra:** OCR, PDF/A-1b, password, tags/search, auto-export, cloud backup.
**Price:** ₹4,250/year, 1-week trial.

`02_genius_compare_plans.png`, `02_genius_ultra_paywall.png`

**Document detail:** date/time title, Add tag, Text recognition, Document history, Export, More. OCR gate goes to Ultra.

`02_genius_editor.png`, `02_genius_ocr_gate.png`

**Lesson:** a concrete two-column Free/Ultra matrix is better than a vague PRO band. Genius sells document work, not ads.

## SwiftScan — the strongest export row

**After save:** PDF title/time, watermark, Edit, Remove Watermark, AI Tools, Share / Email / JPG / Fax / Drive / OneDrive / Dropbox / Print.

`03_swiftscan_library2.png`

**Review:** Add pages / Filter (crown) / Crop / Rotate / Delete, full-width page.

`03_swiftscan_review.png`

**VIP:** limited scan/upload, AI, cloud, editing, signature, OCR; ₹2,350/year or ₹470/month.

`03_swiftscan_paywall.png`

## What ScanWhirl should copy in the PDF manager

1. **A central “PDF Tools” entry** with recent PDFs directly underneath.
2. **A tool group**, not a flat sheet: Organize / Optimize / Convert / Secure / Finish.
3. **A document row with thumbnail, pages, size, date, lock badge and `⋯`.**
4. **A persistent viewer dock** with Share/Edit/Text/Export/More.
5. **A post-save result screen** with before/after, Open/Share/Show in library/Undo.
6. **A real Free vs Power Pack matrix**, not a mystery PRO badge.
7. **Naming and folders/tags** so files are findable after the operation.

## What not to copy

- Ads, watermark, full-screen upsells, cloud-first storage.
- 41 tools and 194 MB of native/ad/cloud code.
- Account/points/EDU/widgets before the core document job is done.
- “PDF/A” or “Word” labels without fidelity/compatibility proof.
- Excel/PPT conversion before text/Word is solid.
- Editing a PDF’s text layer as if the app is Acrobat; current ScanWhirl is page-image based.
